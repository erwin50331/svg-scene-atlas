    使用方式

    1. 下載 HTML

      每組有兩種版本。「純插畫版」只有動畫畫面，會自動日夜循環，畫面上的東西一樣可以點；「完整版」多了日夜切換按鈕和互動說明。都是單一檔案，直接用瀏覽器打開，或用 <iframe> 嵌進你的網頁。

    2. 改色票

      打開檔案，最上面的 :root 區塊就是全部顏色，白天和夜晚各一組。改完存檔，整個場景一起換色。

    3. 用 Prompt 做自己的版本

      按「複製 Prompt」，貼到你自己的 Claude 對話，換掉地點、風格或互動，就能生成新的場景。用的是你自己的帳號，這個網站不需要也不會保存任何金鑰。

    嵌入範例

    <iframe src="SC-17-vienna-ring-tram-lineart-pure.html"
        style="width:100%;aspect-ratio:8/3;border:0"
        title="維也納莫札特花園"></iframe>
