# 聲音

所有聲音都用 Web Audio 即時合成，不用任何音檔，所以整個作品還是單一 HTML 檔。

## 架構

```
音效（sfxBus）──┐
                ├─ master ─ 壓縮器 ─ 喇叭
音樂（musBus）──┘   （musBus 預設 0.64）
```

- **分兩軌**：音樂軌和音效軌分開。
- **同軌換聲**：同一軌有新聲音時，舊的淡出（`newTrack()`）。
- **讓位**：音樂響起時，音效軌轉小聲（`duckSfx(秒數)`）。
- **聲音關**：所有聲音立刻全停。
- **自動播放限制**：瀏覽器規定要等使用者第一次點擊後才建立或恢復 AudioContext。
- **背景配樂**：如果另外用 `tools/scene-bgm.js`，場景的秀音樂要呼叫 `window.sceneMusic.duck(秒數)`，讓配樂先讓位。

## 音量

- 音樂軌主音量預設 **0.64**，太大聲會蓋過畫面，聽起來很吵。
- 音效軌維持 1，個別音效的音量控制在 0.02～0.15。
- master 後面接一個壓縮器（threshold 約 -16、ratio 約 3），避免突然爆音。

## 配樂的和聲規則（最重要）

聽的人對不和諧非常敏感，請嚴格遵守：

1. 先決定調性與和弦進行，例如 C – Am – F – G。
2. 旋律在**強拍上的音一定要是當下和弦的組成音**。
3. 經過音只能放在弱拍，而且要短（一格以內）。
4. 鐘琴、鐘聲類的泛音只用**整數倍**（1、2、3、4 倍），不要用 2.76 倍這種會走音的比例。
5. 低音走和弦根音或五度。
6. 多個聲部同時響時，檢查有沒有小二度或大七度撞在一起。
7. 寫完後列出每小節的和弦與旋律強拍音，逐小節核對一次。

## 秀的音樂

- 約 20 秒內。
- 有開場、高潮、收尾。
- 結尾要落在主和弦。
- 曲風貼合在地文化，例如峇里島用甘美朗音階、愛爾蘭用錫口哨與豎琴，但旋律要原創。
- 兩段秀的音樂不會同時響，因為兩段秀本來就不能同時進行。

## 音效

- **做法**：用濾波噪音與振盪器做風聲、雨聲、浪聲、蟲鳴、腳步、鈴聲、水花等。
- **連動**：環境聲跟著天氣和時段變化，例如雨天有雨聲、夜裡有蟲鳴。
- **不要做**：
  - 不要合成人聲，包括說話、唱歌、歡呼。
  - 不要自動冒出喇叭聲或汽笛聲，只有使用者點了才響，而且要短。
