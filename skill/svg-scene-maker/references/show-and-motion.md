# 秀、表演氛圍與動態

## 什麼是「秀」

秀是這個場景最值得按的一顆大按鈕：一段約 15～20 秒、有起承轉合、配上專屬音樂的小劇場。好的秀會讓人想把網址傳給朋友。

**好例子**
- 煙火大會的大結局，煙火鋪滿左右兩側
- 上千隻紅鶴從湖面起飛，繞一圈再降落
- 燭光守夜時四百多盞蠟燭一盞盞亮起
- 百顆熱氣球同時升空
- 鯨鯊從頭頂游過
- 冬季黃昏的瀑布被夕陽照成火紅色

**設計原則**
- 用場景最有代表性的東西當主角：地標、在地節慶、招牌動物、知名自然現象。
- 規模要大、畫面要滿，敢跳脫框架會被稱讚，例如改成第一人稱視角坐上雲霄飛車。
- 有開場、高潮、收尾三段，收尾要回到平常的樣子。
- 秀開始時可以自動把時段調到最好看的時刻（例如黃昏、夜晚），結束後還原使用者原本的設定。
- 一個場景最多兩段秀，兩段不能同時進行；表演中按別的秀，就跳出小泡泡說「表演進行中，等一下喔！」。
- 秀中不要冒出一大堆文字框，最多一兩句短短的泡泡。

## 表演氛圍（取代寬銀幕黑邊）

不要加上下黑邊。改用 `#cineFx` 圖層（骨架已附），效果是四周輕微暗角、中央微亮：

- 開場 `setCine(k)` 用約 2.5 秒從 0 淡到 1，收尾再淡回 0。
- 可以傳入光源位置 `setCine(k, x, y)`，讓中央亮處跟著主角。
- 鏡頭推近幅度要小（約 3～5%）；物件很多、會卡的場景就不要推近。

## 再按一下優雅停止（ShowStop）

播放中的秀鈕會顯示「■ 停止」，再按一下時：

- 畫面凍結成殘影，約 1.8 秒淡出，底下已經回到表演前的狀態。
- 還沒響的音符取消，正在響的長音淡出，表演排程的計時器全部取消。

**做法**
1. 場景主程式裡要有 `show.on`（表演中為真）、`endShow()`（立刻結束並清掉秀中物件），以及 `setCine()`。
2. 寫一個 adapter 檔，例如 `adapter.js`：

```js
ShowStop.init({
  on: () => show.on || null,                     // 多段秀時回傳種類，例如 'fire'、'stars'
  btn: { fire: 'btnFire', stars: 'btnStars' },   // 只有一段秀時可以直接寫 'btnShow'
  save: () => ({ t: T.t, auto: T.auto }),        // 表演前記下使用者設定
  restore: s => { T.t = s.t; T.auto = s.auto; applyTime(true); },
  stop: () => { endShow(); setCine(0); }
});
```

3. 執行 `python3 tools/showstop_inject.py 場景.html adapter.js`。模組會放在主程式之前，adapter 放在主程式最後一個 `})();` 之前。工具可以重複執行，會自動換掉舊版。

## 移動物的規則

- **朝向**：船、車、動物、鳥的朝向必須跟行進方向一致，包括車頭、車燈和輪子的轉向。往左走就整個翻過來。
- **避讓**：多艘船、多台車、多個人或動物之間要互相避讓，不能穿模。同一條路上的車要保持車距，跟車時要減速。
- **人群**：
  - 身高要有高有矮，不要一排頭一樣高。
  - 衣服顏色要鮮豔多樣。
  - 人數參考：一般節慶場景約 20～30 人；著名人潮景點約 40～50 人；使用者主動要「人山人海」才上百人。
- **在地感**：人物、動物、交通工具要符合當地真實情況，例如在地的計程車樣式、在地物種。

## 動態與效能

- 用一個 `requestAnimationFrame` 主迴圈推進所有動畫，不要每個物件各開一個計時器。
- 分頁隱藏時暫停；`prefers-reduced-motion` 時停掉大幅移動與閃爍，只保留緩慢變化。
- 大量重複的小物件（人群、雨滴、星星、筆觸）用 `<use>` 或一條 path 一次畫完，每幀只更新必要的屬性。
- 大面積的透明度變化要量化（例如每 0.01 才更新一次），避免每幀重繪。
- 不要對大圖層做濾鏡動畫。
- 滑鼠移動時各層產生視差，遠層動得少、近層動得多。
- 天氣切換要有明顯差別：雲量、光線、雨雪粒子、地面反光、人物撐傘等都要跟著變。
