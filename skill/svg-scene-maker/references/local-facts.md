# 在地細節查證

畫錯在地細節是最容易被看出來、也最傷作品可信度的錯，例如熱氣球出現在當地根本不放熱氣球的地方，或朝聖者的衣著不對。所以**每個在地元素都要先查證，再動筆**。

## 做法

1. 開工前列一張「在地元素表」，每一列寫：元素、畫面上的樣子、依據（官方網站、百科、旅遊局、新聞照片的描述）、把握程度（確定／不確定）。
2. 「不確定」的項目不要硬畫：換成確定的元素，或先問使用者。
3. 不要用「大概每個城市都有」的通用素材填空，例如隨手加熱氣球、棕櫚樹、海鷗、雙層巴士、櫻花。每一個都要確認這個地點、這個季節真的有。
4. 交件時把在地元素表附在說明裡，讓使用者可以快速核對。

## 一定要查的項目

| 類別 | 要確認什麼 | 常見地雷 |
|---|---|---|
| 地標 | 輪廓、塔數、窗數、顏色、周邊相對位置 | 塔的數量畫錯；左右相反 |
| 天空的東西 | 熱氣球、飛機、直升機、風箏、鳥種是否真的出現在這裡 | 熱氣球出現在不放熱氣球的城市 |
| 人物衣著 | 宗教服飾、傳統服、制服、當季穿著 | 朝聖者衣著不符儀式規定；夏天穿大衣 |
| 交通 | 靠左或靠右行駛、計程車與公車樣式和顏色、船型 | 靠左行駛的國家車子開在右邊 |
| 動植物 | 當地真的有的物種、季節、出沒時段 | 把別洲的動物放進來；夜行動物白天出現 |
| 文字 | 招牌用當地文字，但不放真實品牌 | 招牌語言錯；出現商標 |
| 天文與氣候 | 日出日落方位、極光只在高緯度、雨季與乾季 | 赤道附近畫極光；乾季畫雨景 |
| 節慶與習俗 | 日期、季節、儀式的順序與道具 | 節慶跟畫面季節對不上 |

## 季節一致

- 同一個畫面只能有一個季節：樹葉、衣著、天色、活動都要對上，例如滑雪跟跳海不會是同一天。
- 秀可以換時段（例如調到夜晚放煙火），但不能換季節。
