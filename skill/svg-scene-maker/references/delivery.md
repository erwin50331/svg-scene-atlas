# 輸出與下載

作品最後是要給人拿去用的，所以交付的格式和下載的體驗也要設計。

## 交付的檔案

- **檔名**：英文小寫加連字號，`SC-編號-地點-主角.html`，例如 `SC-19-lisbon-tram.html`。不要用空白或全形字，避免在不同系統上變成亂碼。
- **編碼**：UTF-8，開頭有 `<meta charset="utf-8">`。
- **離線可開**：直接雙擊用 `file://` 打開也要能動，不依賴伺服器、字型服務或外部網址。
- **兩種版本**：
  - 完整版：含控制列（`.panel`）與說明（`ul.hint`）。
  - 純插畫版：只有畫面。骨架的結構讓你只要加一段 CSS 隱藏 `.panel` 與 `.hint`，畫面就會填滿，點擊互動和日夜循環都保留。寫的時候不要讓畫面依賴控制列才能正常運作。
- **聲音可拆**：場景音效與背景配樂分開，背景配樂放在 `<script id="scene-bgm">` 裡，方便下載時拿掉。拿掉後畫面不能報錯。

## 影片與動圖（要錄的話）

| 格式 | 規格 | 用途 |
|---|---|---|
| MP4 | 1920×720，約 25 秒，含配樂，頭尾可以無縫循環 | 社群、簡報 |
| GIF | 800 像素寬，約 8 秒，無聲循環 | 聊天、文件 |

錄影時用固定的時脈推進動畫（不要依賴真實時間），聲音用 OfflineAudioContext 另外算出來，確保畫面與聲音同步、每次錄出來都一樣。

## 下載按鈕的設計（做作品集網站時）

- 按下去先跳出選項，不要直接下載：格式（HTML／MP4／GIF）、版本（純插畫／完整）、聲音（音效、配樂可分別勾選）。
- 沒有聲音的作品要直接說明「下載後是靜音的動畫」，不要顯示用不到的選項。
- 按下後要有回饋：箭頭落下 → 進度圈 → 打勾，約 1 秒，再跳出小提示寫出檔名。
- 在別人的頁框（iframe）裡，瀏覽器可能擋下載，改開新分頁。
- 下載的檔案就是原作，不要重新上色或改字型。
