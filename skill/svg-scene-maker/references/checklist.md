# 驗收清單

逐條打勾，全部通過才算完成。前四類是看的人最容易「覺得怪」的地方，技術類是基本功。

## 一、在地細節查證（詳見 `local-facts.md`）
- [ ] 已列出在地元素表，每一項都有依據；不確定的已換掉或問過使用者
- [ ] 地標一眼認得出來，輪廓、數量、左右位置正確
- [ ] 天上的東西（熱氣球、飛機、鳥種）在這個地點真的會出現
- [ ] 人物衣著符合當地、宗教儀式與季節
- [ ] 交通工具樣式在地，靠左或靠右行駛正確
- [ ] 動植物是當地、當季真的有的
- [ ] 招牌用當地文字，沒有真實品牌或商標
- [ ] 同一畫面只有一個季節，天氣、活動、衣著都對得上
- [ ] 名稱是「地名＋畫面主角／時刻」，有趣不平淡
- [ ] 只有原創內容，沒有既有角色

## 二、物理上的舒適（詳見 `show-and-motion.md`「移動物的規則」「步態與物理」）
- [ ] 動物、車、船、鳥、飛機的朝向跟行進方向一致，車頭、車燈、輪子都對
- [ ] 移動物互相避讓，沒有穿模；同一條路上保持車距
- [ ] 路人步速不快（一般走路每秒約 0.7～0.8 個身高），雙腳擺動每秒約 1.6～2 步
- [ ] 擺腳跟移動速度連動，腳不會在地上滑；站著的人不踏步
- [ ] 人群速度、步頻各有差異，不會整群同步
- [ ] 車輪轉速跟車速一致，起步停車有加減速
- [ ] 煙、旗、樹、雲、雨的風向一致
- [ ] 人車動物都踩在地上，影子方向跟太陽一致，倒影對齊
- [ ] 人群高矮不一，人數符合場景（節慶 20～30、知名人潮景點 40～50）

## 三、使用體驗的舒適
- [ ] 任何時刻只有一段音樂在響，兩段音樂不會疊在一起
- [ ] 同一軌換聲時舊的淡出；音樂響起時音效轉小聲
- [ ] 「聲音關」會立刻全停；沒有自動冒出的喇叭或汽笛聲，沒有合成人聲
- [ ] 秀播放中按鈕顯示「■ 停止」，再按一下約 2 秒淡出停止（ShowStop 已注入）
- [ ] 兩段秀不能同時進行；結束或停止後，時段與天氣回到表演前的設定
- [ ] 表演沒有上下黑邊，用 `#cineFx` 暗角＋中央微亮，約 2.5 秒淡入淡出
- [ ] 至少 6 個可以點的東西，每個都有明確反應；沒有跟「點角色」重複的按鈕
- [ ] 時段用一顆按鈕輪播，另有自動播放開關；多變天氣有多種天氣可切換
- [ ] 底下說明最多約 5 條，條列短句
- [ ] 鍵盤可以操作：可點物件有 `tabindex` 與 `role="button"`，Enter 會觸發
- [ ] 一般電腦上順暢不掉幀，表演時也一樣；分頁隱藏時暫停
- [ ] 檔名、版本、聲音可拆都符合 `delivery.md`；直接雙擊打開就能動

## 四、構圖與美感（詳見 `composition.md`）
- [ ] 有前、中、後景，外加不擋主角的前景框景
- [ ] 地平線約在畫面高度 55～65%，上半部不空，下緣有東西撐住
- [ ] 主角一眼找得到，左右兩側都有內容，有疏有密
- [ ] 白天也熱鬧；白天、黃昏、夜晚、清晨四個時段都好看，夜裡有燈光
- [ ] 整個畫面同一種畫風，人物造型也一致
- [ ] 考慮過一個創意視角（例如第一人稱），並讓使用者挑過
- [ ] 秀規模夠大、有開場高潮收尾，約 20 秒內
- [ ] 畫面裡沒有作品名稱或編號標籤

## 五、技術
- [ ] 單一 HTML 檔，沒有外部資源
- [ ] 顏色全部集中在開頭的 CSS 變數
- [ ] 音樂軌主音量 0.64；旋律強拍都在和弦音上，鐘琴只用整數泛音，逐小節核對過
- [ ] 支援 `prefers-reduced-motion`
- [ ] 瀏覽器 console 沒有錯誤
- [ ] 手機寬度下控制列會換行，畫面不超出
- [ ] 程式碼有中文註解，分好「場景、角色、動畫、互動」各區塊
