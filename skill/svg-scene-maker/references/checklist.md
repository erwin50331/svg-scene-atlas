# 交件前品質檢查

逐條打勾，全部通過才算完成。

## 內容
- [ ] 地標一眼認得出來，在地元素寫實、沒有編造
- [ ] 名稱是「地名＋畫面主角／時刻」，有趣不平淡
- [ ] 季節與天氣邏輯合理，同一畫面不混季節
- [ ] 畫面上半部不空：天空有雲、鳥、熱氣球、飛機、星星等
- [ ] 白天也熱鬧，有在地人物、動物、交通工具在活動
- [ ] 只有原創內容，沒有既有角色、品牌或商標
- [ ] 畫面裡沒有作品名稱或編號標籤

## 畫風
- [ ] 整個畫面同一種畫風，人物造型也一致
- [ ] 白天、黃昏、夜晚、清晨四個時段都好看，夜裡有燈光
- [ ] 顏色全部集中在開頭的 CSS 變數

## 互動
- [ ] 至少 6 個可以點的東西，每個都有明確反應
- [ ] 沒有跟「點角色」重複的按鈕
- [ ] 時段用一顆按鈕輪播，另有自動播放開關與時間拉桿
- [ ] 當地天氣多變的話有多種天氣，切換效果明顯
- [ ] 滑鼠移動有視差或即時反應
- [ ] 鍵盤可以操作：可點物件有 `tabindex` 與 `role="button"`，Enter 會觸發
- [ ] 底下說明最多約 5 條，條列短句

## 秀
- [ ] 1～2 段秀，每段約 20 秒內，規模夠大、有高潮
- [ ] 沒有上下黑邊，改用 `#cineFx` 暗角＋微亮，約 2.5 秒淡入淡出
- [ ] 再按一次顯示「■ 停止」，按下去會優雅停止（ShowStop 已注入）
- [ ] 兩段秀不能同時進行
- [ ] 結束或停止後，時段、天氣都回到表演前的設定

## 動態
- [ ] 所有移動物朝向正確，車頭、車燈、輪子都對
- [ ] 移動物互相避讓，沒有穿模
- [ ] 人群高矮不一，衣服鮮豔
- [ ] 一般電腦上順暢不掉幀，表演時也一樣
- [ ] 支援 `prefers-reduced-motion`；分頁隱藏時暫停

## 聲音
- [ ] 音樂軌與音效軌分開，音樂軌主音量 0.64
- [ ] 旋律強拍都在和弦音上，鐘琴只用整數泛音，逐小節核對過
- [ ] 「聲音關」會立刻全停
- [ ] 沒有合成人聲，沒有自動冒出的喇叭或汽笛聲

## 技術
- [ ] 單一 HTML 檔，沒有外部資源
- [ ] 瀏覽器 console 沒有錯誤
- [ ] 手機寬度下控制列會換行，畫面不超出
- [ ] 程式碼有中文註解，分好「場景、角色、動畫、互動」各區塊
