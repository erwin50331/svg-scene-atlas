# 構圖與視角

這部分比較主觀，但有幾條經驗很穩定。開工前先提出構圖，讓使用者確認再畫。

## 前中後景

- 至少分三層：遠景（天空、山、天際線）、中景（地標與主要活動）、近景（地面、人物、物件），再加一層**前景框景**。
- 前景框景是貼著畫面邊緣、局部入鏡的東西，例如樹枝、欄杆、屋簷、船頭、近處的人影。它讓畫面有深度，也讓滑鼠視差更明顯。
- 前景不能擋住主角或可點的東西，面積控制在畫面的一成左右。
- 越遠的層顏色越淡、對比越低、動得越慢。

## 上下構圖

- 地平線大約放在畫面高度的 55～65%：天空有空間放雲、鳥、飛機、星星，地面也有舞台讓人物活動。
- 畫面上半部不能空：白天要有雲、鳥或在地真的有的飛行物，夜晚要有星星、月亮或燈光。
- 下緣不要只有一條平平的地面，要有前景物件或人物把底部撐起來。

## 主角與視線

- 主角（地標或主要事件）要一眼找得到，放在約三分之一處；對稱的地標可以放正中央。
- 用光線、顏色、人群的走向把視線帶到主角，不要讓四周的小物件搶戲。
- 左右兩側都要有內容，不要一邊熱鬧、一邊空蕩。
- 物件之間有疏有密，留一點呼吸空間，不要每一處都塞滿。

## 創意視角

- 除了平視全景，也可以考慮跳脫框架的視角：第一人稱（坐在纜車、雲霄飛車、船頭上）、從水下往上看、從窗內往外看、鳥瞰。
- 選題時至少想一個不一樣的視角供使用者挑選；敢跳脫框架通常會被稱讚。
