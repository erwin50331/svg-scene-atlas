# SVG 動畫場景製作

這份 skill 是《SVG 動畫圖鑑》101 組作品累積下來的做法。目標是做出一個**單一、自包含的 HTML 檔**：打開就是一幅 1600×600 的寬幅插畫，會隨時間流動、可以點、有一兩段值得按的「秀」，還有好聽的原創配樂。

## 什麼時候讀哪個檔

| 檔案 | 內容 | 什麼時候讀 |
|---|---|---|
| `references/styles.md` | 20 種畫風的具體 SVG 畫法 | 決定風格時（每次都要讀對應段落） |
| `references/show-and-motion.md` | 秀的設計、表演氛圍、優雅停止、移動物規則 | 寫秀與動畫前 |
| `references/sound.md` | 聲音架構、配樂和聲規則、音量 | 寫聲音前 |
| `references/checklist.md` | 交件前的品質檢查清單 | 交件前逐條自檢 |
| `templates/scene-skeleton.html` | 可直接執行的最小場景骨架 | 開工時複製一份當起點 |
| `tools/showstop.js`＋`tools/showstop_inject.py` | 「表演再按一下優雅停止」共用模組與注入工具 | 有秀的場景都要用 |
| `tools/scene-bgm.js` | 可換曲譜的背景配樂引擎 | 想要常駐背景音樂時 |

## 工作流程

1. **選題與命名**
   - 用大眾熟悉的真實地點，名稱是「地名＋畫面主角／時刻」，要有趣，例如「東京隅田川的花火大會」「優勝美地隧道景觀的四季」。
   - 地標要一眼認得出來；在地元素要寫實、查證過，不要編造。
   - 季節邏輯要合理：同一個畫面不要同時出現滑雪和跳海。
2. **選風格**：從 `references/styles.md` 挑一種，整個畫面（包含人物造型）都要跟畫風一致。
3. **列出內容**，開工前先跟使用者確認：
   - 地標與主角、在地人物與動物、交通工具
   - 環境動態（風、雲、水、煙、燈）
   - 天氣種類（當地天氣多變就要有多種，而且效果要明顯）
   - 6～10 個可以點的東西
   - 1～2 段秀（見 `show-and-motion.md`）
4. **從骨架開始寫**：複製 `templates/scene-skeleton.html`，保留它的結構（`body > main.wrap > figure.stage > svg#scene`，加上 `.panel` 控制列與 `ul.hint` 說明）。
5. **畫場景**：由遠到近分層，依序是天空 → 遠景 → 中景地標 → 地面 → 人物與物件 → 前景 → 特效 → `#cineFx`。
6. **加動態與互動**：日夜循環、天氣、點擊反應、滑鼠視差。
7. **加秀與聲音**：秀用 ShowStop 注入優雅停止（`python3 tools/showstop_inject.py 場景.html adapter.js`）；配樂照 `sound.md` 的和聲規則。
8. **自檢**：照 `references/checklist.md` 逐條檢查，並用瀏覽器實際打開，確認不卡、不報錯、白天夜晚都好看。

## 不能妥協的規則

- **技術**：
  - 單一 HTML 檔，只用 SVG＋原生 JavaScript，不用外部函式庫、圖檔或音檔。
  - viewBox 固定 `0 0 1600 600`，RWD 縮放。
  - 所有顏色集中在開頭的 CSS 變數，白天、夜晚各一組。
  - 支援 `prefers-reduced-motion`。
  - 程式碼加中文註解，標出「場景、角色、動畫、互動」各區塊。
- **原創**：
  - 只畫原創內容，不用既有角色、品牌、商標。
  - 參考電影或遊戲時只取氛圍或手感，不取造型或特定畫面。
- **畫面**：
  - 畫面上半部不能空。
  - 白天也要熱鬧。
  - 畫面裡不放作品名稱或編號標籤。
  - 手寫字要像可愛的手寫字。
- **操作**：
  - 角色本身可以點的動作，不要再做一顆重複的按鈕。
  - 時段切換用一顆按鈕輪播（白天 → 黃昏 → 夜晚 → 清晨），不要做四顆。
  - 底下說明文字最多約 5 條，條列短句。
- **表演**：
  - 不用上下寬銀幕黑邊，改用輕微暗角＋中央微亮（`#cineFx`）。
  - 每段秀約 20 秒內。
  - 再按一次同一顆鈕要優雅停止。
  - 兩段秀不能同時進行。
- **聲音**：
  - 不合成人聲。
  - 不要自動冒出喇叭或汽笛聲。
  - 旋律落在和弦音上，不能不和諧。
